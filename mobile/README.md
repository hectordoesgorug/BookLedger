# BookLedger Mobile

Flutter companion interface foundation for BookLedger.

The mobile app provides navigation for Single Entry and Bulk Entry, a presentation-only capture screen, queue-size selection (5–20), and a persistent desktop connection status. Camera capture, ISBN scanning, storage, pairing, and transfer are not implemented in this milestone; BookLedger desktop remains the source of truth.

## Development

From this directory:

- `flutter analyze`
- `flutter test`
- `flutter build apk`
